# Light Engine Hardware

Responsibility: emitters, electrical strings, MCPCB/layout, thermal interface,
channel identity, and source geometry presented to the optics.

The architecture permits a low-cost two-white-channel engine and later
multi-channel engines without forcing the premium implementation on every build.

Not yet frozen: emitter family, CCT endpoints, spectral correction wavelengths,
channel count, string voltage/current, MCPCB geometry, and thermal attachment.
