# Controller Hardware

Responsibility: MCU/control electronics, local-control I/O, service/programming
interface, low-voltage rails needed by control electronics, and coordination
interfaces to power/sensor modules.

Not yet frozen:

- MCU family/package.
- Whether BLE is integrated in the controller MCU or implemented by an optional module.
- Display/encoder/button hardware.
- Connector pinout to power and sensor modules.

The folder name intentionally does not encode an MCU choice.
